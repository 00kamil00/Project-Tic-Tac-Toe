# Tic-Tac-Toe

A browser-based Tic-Tac-Toe game built with vanilla JavaScript, HTML, and CSS as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## Features

- Two-player local gameplay (Player X vs. Player O)
- Custom player names input
- Real-time turn indicator and game result announcements (win/tie)
- Restart functionality to reset the board anytime
- Clean separation of concerns using JavaScript Module and Factory Function patterns (minimal global code)

## Tech Stack

- **HTML5** – Markup structure
- **CSS3** – Styling and grid layout
- **JavaScript (ES6)** – Game logic, DOM manipulation, factory functions, and IIFEs/modules
